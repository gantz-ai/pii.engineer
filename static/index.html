Privacy Policy

PII Engineer is committed to protecting your privacy. This policy explains how we handle data when you use our service.

1. Data Processing

No data retention. Text you submit is processed entirely in memory (RAM) and is immediately discarded after the response is sent. We do not write your input to any disk, database, file system, or persistent storage at any point during or after processing.

2. No Third-Party Data Sharing

All inference (Named Entity Recognition and Natural Language Inference) runs locally on our own server. Your data is never sent to any external API, cloud AI service, or third-party processor. We do not use OpenAI, Google, AWS, or any other external service to process your text.

3. No Tracking or Analytics

We do not use cookies, tracking pixels, analytics services, or any form of user identification. We do not collect IP addresses, browser fingerprints, or usage patterns. There are no user accounts or login systems. We have no way to identify who is using the service.

4. Server Logging

Our server logs contain only operational metadata: HTTP status codes, response times, and error codes. Input text is never included in logs. Logs are retained for a maximum of 7 days for debugging purposes and are automatically deleted after that period.

5. Server Location

Our server is hosted on DigitalOcean in the Singapore (SGP1) region. All data processing occurs within this single server. Data does not leave this server or cross jurisdictional boundaries during processing.

6. Security

All connections are encrypted with TLS (HTTPS). The server runs on dedicated infrastructure with automatic security updates. Access to the server is restricted to SSH key-based authentication only.

7. Changes to This Policy

We may update this policy from time to time. Changes will be reflected in the "Last updated" date below. Continued use of the service constitutes acceptance of any changes.

8. Contact

If you have questions about this privacy policy or our data practices, contact us at techadmin@pilotpulse.ai.
